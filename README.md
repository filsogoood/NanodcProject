# NANODC: An Integrated Platform for Decentralized Infrastructure and Token Economy

NANODC (Nano DePIN Center) is evolving beyond mere hardware into an integrated platform that combines decentralized data infrastructure operation with a transparent token economy.

The NANODC is an ultra-compact decentralized data center, designed to overcome the limitations of traditional large-scale data centers by allowing installation in small spaces of about 9.9 ㎡ (3 pyong) to contribute to the DePIN (Decentralized Physical Infrastructure Network).


### Key Features and Concept of NANODC

| Category | Description |
|-------|-------|
| Concept | Nano DePIN Center (Nano Decentralized Physical Infrastructure Network Center) |
| Size | Requires only a small space of about 9.9 ㎡ (approx. 3 pyong / 106 sq. ft.), reduced to about 1/40th the size of conventional equipment. |
| Ease of Installation | Can be installed and operational in just one day in any location with a power supply of 15 kW or more. |
| Design | All-in-one design where all functions, including UPS, battery, communication, and monitoring, are integrated into a single rack. |
| Main Functions | Establishes decentralized distributed storage (IPFS/Filecoin based) and can include GPU-based servers (SAI) for AI systems. |
| Maximum Storage | A single equipment set can store up to 12 PiB (12,000 Terabytes) of data. |

## NanoDC Project

### 1. Real-Time Operational Transparency and Monitoring System

The NANODC project offers a system designed to maximize operational transparency:

- **Real-Time Status Confirmation**: The system allows users to check the installation information and operational status of all NANODC nodes in real-time. This is a key factor in enhancing the reliability of the distributed physical infrastructure.

- **Intuitive Management**: Through a touchscreen embedded in the ultra-compact all-in-one rack, even non-experts can easily monitor and manage the node's operational status.

<br>

### 2. Integration of DeFi for Reward Structure

NANODC has incorporated decentralized finance (DeFi) elements to establish a framework for user participation and a transparent reward structure.

- **Asset Custody and Reward Functionality**: Users can hold their assets in custody and receive rewards, such as Filecoin (FIL), generated through node operation.

- **Transparent Reward Dashboard**: A dashboard system is provided to monitor financial activities and the status of reward generation at a glance. This allows users to clearly confirm and manage the compensation for their contributions.

- **Linkage with FiLMountain**: Through systems like FiLMountain—ZetaCube's dedicated DeFi liquidity pool—NANODC owners can achieve high-profit opportunities beyond simple node operation.

<br>

### Evolution into an Integrated Platform

Consequently, NANODC is developing into a platform that integrates real-time operational data, a transparent reward structure, and maximized user participation and profit through DeFi. It presents a new franchise model for data centers based on a token economy, encouraging user participation in the critical infrastructure areas of AI computing and decentralized storage for the Fourth Industrial Revolution.
